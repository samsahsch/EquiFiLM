# EquiFiLM data + model — README

Companion deposit to the NeurIPS 2026 AI for Science anonymous submission
*EquiFiLM: Charge-Conditioned Equivariant Force Fields via Feature-wise Linear Modulation*.

## Contents

| File | Description | Size |
|---|---|---|
| `gs.xyz`   | AIMD trajectory at $q=0$ (neutral / ground-state water) | 48 MB |
| `6e.xyz`   | AIMD trajectory at $q=6e$ added electrons               | 66 MB |
| `10e.xyz`  | AIMD trajectory at $q=10e$                              | 66 MB |
| `16e.xyz`  | AIMD trajectory at $q=16e$                              | 32 MB |
| `E-MACE.model` | Headline E-MACE checkpoint (SWA-final, epoch 249) | 13 MB |

## XYZ format

Each `.xyz` is in standard extended-XYZ format readable by ASE
(`ase.io.read`). Each frame contains:

* Number of atoms (108 H₂O ⇒ 324 atoms total per frame).
* Header line with: cubic `Lattice=...`, periodic boundary conditions
  `pbc="T T T"`, custom info field `total_charge=N` (integer; electrons
  *added* relative to neutral water), and the per-atom `Properties`
  schema describing position, forces, etc.
* Per-atom: chemical species (`O`, `H`), Cartesian coordinates (Å),
  reference DFT forces (eV/Å), reference DFT total energy (eV) on the
  `energy` info field.

```python
from ase.io import read
frames = read('gs.xyz', index=':')              # list of Atoms
print(frames[0].info['total_charge'])           # integer charge
print(frames[0].get_potential_energy())          # reference DFT energy in eV
print(frames[0].get_forces().shape)              # (324, 3) DFT forces in eV/A
```

## Cell / density bias (important)

`gs.xyz`, `6e.xyz`, `10e.xyz` were produced at a **13.8 Å** cubic cell
(higher density), while `16e.xyz` was produced at a **14.8 Å** cubic
cell (lower density). The asymmetry is inherited from the upstream
AIMD source data and is documented as a limitation in §6 of the paper.
For molecular dynamics with the released checkpoint, use the
14.8 Å seed configuration (`seed_324atom.xyz`, distributed in the
companion code repo, *not here*) — the model is more numerically
stable at that density.

## DFT reference

Energies and forces were computed with VASP using the r²SCAN
exchange-correlation functional and the omat-ft pseudopotential set;
the same level used by the MACE-MATPES-r²SCAN-omat-ft foundation
model. Smearing: methfessel-paxton order 0, width 0.001 eV for
neutral water and 0.05 eV for charged states (handles partial
occupations near the Fermi level for excess-electron states).

## Trained checkpoint

`MACE-FiLM-large_stagetwo.model` is a PyTorch-saved E-MACE model
loadable via `mace.calculators.MACECalculator`. It was trained for
250 epochs (SWA from epoch 150) on the four `.xyz` files above with
a 90/10 train/val split (seed 123). The held-out validation
indices are deterministic and can be regenerated by the companion
code repo's `examples/eval_per_charge.py`. Headline performance:

| q   | F-RMSE (meV/Å) | E-RMSE (meV/atom) |
|-----|----------------|--------------------|
|  0  |       5.46     |        0.10        |
|  6  |       7.08     |        0.10        |
| 10  |       7.47     |        0.12        |
| 16  |       7.46     |        0.06        |
|mean |     **6.87**   |       **0.10**     |

To use the checkpoint:

```python
import os
os.environ["TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD"] = "1"
from mace.calculators.mace import MACECalculator
calc = MACECalculator(
    model_paths="MACE-FiLM-large_stagetwo.model",
    device="cuda", default_dtype="float32",
    info_keys={"total_charge": "total_charge", "total_spin": "total_spin"},
)
# atoms.info["total_charge"] = 6 etc. before calc.calculate(atoms)
```

The `info_keys` mapping is essential — without it, MACECalculator
defaults remap `total_charge` to a different key and the FiLM
conditioning is silently disabled.

## Code

The accompanying code repository (anonymized for review) is at
**[ANONYMOUS-4OPEN-SCIENCE URL]**. It contains:

* The EquiFiLM patches applied to `mace-torch==0.3.15`
  (four files, drop-in replacements).
* `examples/train.sh` — single command to retrain the checkpoint.
* `examples/eval_per_charge.py` — reproduce per-charge held-out RMSE.
* `examples/md_emace.py` — molecular-dynamics driver used for the
  paper's energy-conservation and Δg(r) / ΔPDF figures.
* `examples/plot_dpdf.py` — smoothed pair-distribution analysis.
* `tests/` — unit tests verifying identity-at-init and
  $E(3)$-equivariance preservation of the FiLM block.

After cloning, install with:

```bash
pip install mace-torch==0.3.15
git clone <anonymous URL>
cd EquiFiLM
pip install -e .
python -m equifilm.apply_patch
```

See `docs/reproduction.md` in the code repo for the full recipe.
